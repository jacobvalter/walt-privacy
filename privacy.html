Privacy policy

Last updated: 30 October 2026

What Walt accesses

Walt asks for read-only access to Google Calendar (calendar.readonly). It reads calendar names and events so that it can show them on the family dashboard.

Where the data is stored

Walt stores the access token and a copy of the events in a database on a home server owned by the family. The data does not go to any other server or service.

Sharing

Walt does not sell, share or transfer Google user data to anyone. Walt does not use the data for advertising or for training AI models. Only family members in the home can see the dashboard.

Google API Services User Data Policy

Walt's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to stop access

You can remove Walt's access at any time at myaccount.google.com/permissions. After that, Walt cannot read your calendar.
